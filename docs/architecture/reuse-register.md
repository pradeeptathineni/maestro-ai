# Architecture reuse register

This register records outside-in prior art that changes the implementation. A link is evidence of a
pattern, not proof that Maestro has reproduced a vendor product or benchmark result.

## Repository mechanisms retained

- PostgreSQL remains the system of record for append-only evidence, receipts, workspace privacy,
  operational leases, and replay.
- Graphile Worker and the transactional outbox remain the single background retry/dispatch owner.
- Existing bounded GitHub, MCP Registry, SearXNG, Hacker News, and loopback structured-model
  adapters remain data acquisition mechanisms.
- TypeBox HTTP contracts, explicit repository SQL, source hashes, and immutable history remain the
  guardrail layer.
- Historical `query-signal-v1` and `query-signal-v2` policies remain replayable.

## Deliberately not adopted

- No general-purpose agent framework or autonomous tool loop.
- No multi-agent fanout until one-agent evaluation demonstrates a concrete limitation.
- No hosted vector or graph database without measured retrieval evidence.
- No cloud/model fallback, model marketplace, or provider router.
- No automatic installation, execution, or permission grant for discovered candidates.
